Required Activation Functions:

Sigmoid: σ(z) = 1 / (1 + e^(-z))

Derivative: σ'(z) = σ(z) × (1 - σ(z))
Range: [0, 1]
Issues: Vanishing gradient


Tanh: tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))

Derivative: tanh'(z) = 1 - tanh²(z)
Range: [-1, 1]
Better than sigmoid (zero-centered)


ReLU: ReLU(z) = max(0, z)

Derivative: ReLU'(z) = 1 if z > 0 else 0
Range: [0, ∞)
Most popular for hidden layers


Softmax: softmax(z_i) = e^(z_i) / Σ(e^(z_j))

For multiclass classification output
Produces probability distribution




📋 Part 2: Perceptron
2.1 Simple Perceptron

Definition: Single-layer neural network
Mathematical Formulation:

Linear combination: z = w·x + b
Activation: ŷ = step(z) where step(z) = 1 if z ≥ 0 else 0


Learning Rule: Weight update based on error

w_new = w_old + α × error × x
b_new = b_old + α × error

📋 Part 3: Multi-Layer Perceptron (MLP)
3.1 Architecture Design

Structure: Input → Hidden Layer(s) → Output
Notation:

L: Total number of layers
n^[l]: Number of neurons in layer l
W^[l]: Weight matrix for layer l (shape: n^[l] × n^[l-1])
b^[l]: Bias vector for layer l (shape: n^[l] × 1)
A^[l]: Activation output of layer l
Z^[l]: Pre-activation output of layer l



3.2 Forward Propagation
Step-by-step equations for each layer:
For layer l (l = 1, 2, ..., L):
Z^[l] = W^[l] · A^[l-1] + b^[l]
A^[l] = f^[l](Z^[l])
Where:

A^[0] = X (input data)
f^[l] is the activation function for layer l
Hidden layers typically use ReLU
Output layer uses Softmax (multiclass) or Sigmoid (binary)

3.3 Matrix Dimensions
For m training examples:

X: (n^[0], m)
W^[l]: (n^[l], n^[l-1])
b^[l]: (n^[l], 1)
Z^[l]: (n^[l], m)
A^[l]: (n^[l], m)


📋 Part 4: Backpropagation Algorithm
4.1 Loss Function
Cross-Entropy Loss (for classification):
For single example: L(ŷ, y) = -Σ(y_i × log(ŷ_i))
For m examples: J = (1/m) × Σ L(ŷ^(i), y^(i))
Mean Squared Error (for regression):
MSE = (1/m) × Σ(ŷ^(i) - y^(i))²
4.2 Chain Rule Derivation
Explain step-by-step how gradients flow backward:
Output Layer (layer L):
dZ^[L] = A^[L] - Y  (for Softmax + Cross-Entropy)
dW^[L] = (1/m) × dZ^[L] · A^[L-1]^T
db^[L] = (1/m) × Σ(dZ^[L])
Hidden Layers (layer l):
dA^[l] = W^[l+1]^T · dZ^[l+1]
dZ^[l] = dA^[l] ⊙ f'^[l](Z^[l])  (⊙ = element-wise product)
dW^[l] = (1/m) × dZ^[l] · A^[l-1]^T
db^[l] = (1/m) × Σ(dZ^[l])

📋 Part 5: Gradient Descent Optimization
5.1 Update Rule
Basic Gradient Descent:
W^[l] := W^[l] - α × dW^[l]
b^[l] := b^[l] - α × db^[l]
Where α (alpha) is the learning rate (typical values: 0.001 - 0.1)
5.2 Variants
Explain and implement:

Batch Gradient Descent:

Uses entire dataset
Most accurate but slow
Update: One per epoch


Mini-Batch Gradient Descent:

Uses batches of size k (e.g., 32, 64, 128)
Balance between speed and accuracy
Most commonly used


Stochastic Gradient Descent (SGD):

Uses one example at a time
Fastest but noisy updates
Update: m times per epoch



5.3 Learning Rate

Too high: Overshooting, divergence
Too low: Slow convergence
Typical starting values: 0.01, 0.001
Learning rate scheduling (optional)
